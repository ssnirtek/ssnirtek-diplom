# Дипломный проект «Businka»

**Тема:** Информационная система интернет-магазина украшений  
**Стек:** PHP, Yii2, MySQL, Bootstrap 5

---

## Аннотация

Разработана ИС интернет-магазина украшений из бисера «Businka»: каталог, корзина, избранное, заказы, акции, отзывы, админ-панель, приветственная скидка 15% на первые 2 заказа. Реализованы аутентификация, модерация отзывов, защита данных. Протестировано 96 проверок (99% успешно).

## Введение

Рынок украшений активно переходит в онлайн. Покупатели ожидают удобный каталог, персональные скидки и безопасное оформление заказа.

**Цель** — разработка ИС «Businka» для розничной онлайн-торговли украшениями ручной работы.

**Задачи:** анализ предметной области → требования → проектирование БД и интерфейсов → реализация → тестирование → руководства → меры безопасности.

---

## 1. Анализ предметной области

### 1.1 Предметная область

Онлайн-продажа украшений из бисера: колье, серьги, браслеты, кольца, аксессуары.

**Бизнес-процессы:** каталог → регистрация → корзина/избранное → заказ → акции → отзывы → администрирование.

### 1.2 Аналоги

Изучены Sokolov, Sunlight, Pandora. Для «Businka» приняты: гибкие акции, view для корзины, избранное, модерация отзывов, приветственная скидка.

### 1.3 Требования

**Функциональные (12):** регистрация/email, роли user/admin, каталог с фильтрами, карточка товара, корзина, избранное, заказы, скидка 15% на 2 первых заказа, акции, отзывы после покупки, админ-панель.

**Нефункциональные:** отклик ≤ 2 с, адаптив от 320 px, хеш паролей, FK и уникальные индексы, интерфейс на русском.

### 1.4 Стек технологий

| Слой | Технология |
|------|------------|
| Backend | PHP ≥ 7.4, Yii2 |
| БД | MySQL |
| Frontend | HTML, CSS, JS, Bootstrap 5 |
| Почта | Symfony Mailer |
| Безопасность | bcrypt, CSRF, ORM |

## 2. Проектирование

### 2.1 Архитектура MVC

| Модуль | Контроллеры |
|--------|-------------|
| Аутентификация | `SiteController`, `UserController` |
| Каталог | `CatalogController`, `ProductController` |
| Корзина / избранное | `CartController`, `FavoriteController` |
| Заказы | `OrdersController` |
| Акции | `AdminPromoController` |
| Отзывы | `ProductController`, `AdminController` |
| Админ | `AdminController` |

**Структура проекта:** `config/`, `controllers/`, `models/`, `views/`, `web/`, `migrations/`, `components/`, `mail/`.

Цены товаров — в модели `Product` (`getFinalPrice()`). Суммы корзины — через view `v_cart_details`.

### 2.2 База данных

БД `sisoeva_diplom`: **10 таблиц + 1 представление**.

| Таблица | Назначение | Ключевые поля |
|---------|------------|---------------|
| `user` | Пользователи | email, password_hash, is_admin, токены |
| `category` | Категории | category_name, description |
| `product` | Товары | price, old_price, is_discount, quantity, is_active |
| `promo`, `promo_product` | Акции | discount_percent, даты, price_discount |
| `cart`, `cart_item` | Корзина | user_id, product_id, quantity |
| `orders`, `order_item` | Заказы | status, subtotal/welcome/total_amount, price |
| `favorites` | Избранное | user_id + product_id (unique) |
| `reviews` | Отзывы | rating 1–5, is_approved |
| `v_cart_details` | View | total_price, original_total |

**Связи:** user → cart, orders, favorites, reviews; category → product; promo ↔ product через promo_product.

**Статусы заказа:** `pending`, `processing`, `completed`, `cancelled`.

### 2.3 Интерфейсы

Палитра (`tokens.css`): `#282826`, `#efece1`, `#ff4081`, `#6c991d`.

**Экраны:** главная, каталог, карточка товара, корзина, оформление заказа, ЛК, админ-панель, контакты, политика конфиденциальности, страница 404.

## 3. Реализация

### 3.1 Основные функции

| Функция | Реализация |
|---------|------------|
| Регистрация | `User`, bcrypt, email_confirm_token, валидация (email, пароль ≥8, ФИО кириллица) |
| Каталог | фильтры, сортировка, AJAX-пагинация |
| Цены | обычная скидка + акции через `getPromoPriceInfo()` |
| Корзина | `Cart::getCurrentCart()`, view `v_cart_details`, только для авторизованных |
| Заказ | транзакция: orders + order_item, списание остатка, очистка корзины |
| Приветственная скидка | 15% на 2 первых заказа → `welcome_discount_amount` |
| Отзывы | только после покупки, `is_approved = 0` до модерации |
| Избранное | `Favorite::toggle()` через AJAX |

### 3.2 Маршруты

| URL | Назначение |
|-----|------------|
| `/` | Главная |
| `/catalog` | Каталог |
| `/product/view?id=N` | Товар |
| `/cart` | Корзина |
| `/orders/create` | Оформление |
| `/user/create`, `/site/login` | Регистрация / вход |
| `/site/contact`, `/site/policy` | Контакты / политика |
| `/admin` | Админ-панель |

### 4.2 Функциональность

- **Ссылки:** меню, подвал, ЛК, админ — работают; `/site/policy` — реализована.
- **Формы:** регистрация, вход, заказ, отзыв, админ-CRUD — валидация на клиенте и сервере, CSRF, данные в БД.
- **Cookie/сессии:** PHPSESSID, «Запомнить меня», cookieValidationKey, localStorage для баннера cookie.

- FK, уникальные индексы, транзакции при заказе, откат при ошибке.

### 4.4 Юзабилити и совместимость

- Навигация без кнопок браузера; понятные статусы и сообщения на русском.
- Браузеры: Chrome, Firefox, Edge, Яндекс, Safari.
- Разрешения: 320–1920 px; `@media print` для заказов и профиля.

### 4.5 Безопасность

| Проверка | Результат |
|----------|-----------|
| Доступ к `/admin` без прав | Блокировка |
| Чужой заказ | 404 |
| SQL-инъекция | ORM / bind-параметры |
| XSS | `Html::encode()` |
| CSRF | Токены Yii2 |
| Пароли | bcrypt-хеш |

**Замечание:** Gii-CRUD (`ProductController`) — закрыть на production; управление через `/admin/*`.

### 4.6 Исправленные дефекты

1. Дублирование `cart_item` при двойном клике — проверка перед вставкой.
2. Акция без учёта `end_date` — исправлено в `Product`.
3. Битое изображение — заглушка `no-image.jpg`.

## 5. Руководства

### 5.1 Администратор

1. Вход: `/admin/login` (только `is_admin = admin`).
2. **Дашборд:** заказы, товары, остатки, пользователи, акции.
3. **Товары:** добавление, редактирование, `is_active`, остаток (AJAX).
4. **Акции:** `/admin-promo` — процент, даты, привязка товаров.
5. **Заказы:** смена статуса pending → processing → completed / cancelled.
6. **Отзывы:** одобрение / скрытие / удаление.
7. **Пользователи:** блокировка, назначение admin.

### 5.2 Пользователь

1. **Регистрация** → подтверждение email.
2. **Каталог** → фильтры, «♥», «В корзину».
3. **Корзина** → количество, скидка 15% на первые 2 заказа.
4. **Заказ** → контакты и адрес.
5. **ЛК** → профиль, заказы, избранное.
6. **Отзыв** → после покупки, публикуется после модерации.

## 6. Информационная безопасность

1. bcrypt-хеши паролей, роли user/admin.
2. ORM и параметризованные запросы — защита от SQL-инъекций.
3. `Html::encode()` — защита от XSS.
4. CSRF-токены во всех формах.
5. Токены сброса пароля и подтверждения email.
6. FK, транзакции, `AccessControl` в контроллерах.
7. Рекомендация: резервное копирование БД и `web/images/`.
