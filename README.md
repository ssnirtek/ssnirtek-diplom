# Bijouterie.ss — интернет-магазин украшений из бисера

Дипломный проект: информационная система для розничной онлайн-торговли украшениями ручной работы.
Политехнический колледж городского хозяйства, специальность «Разработчик веб и мультимедийных приложений», 2026.

**Стек:** PHP 7.4+, Yii2 (MVC), MySQL, Bootstrap 5, JavaScript (AJAX), Symfony Mailer

## Возможности

**Для покупателя**
- каталог с фильтрами, сортировкой и AJAX-пагинацией; карточка товара с обычными и акционными ценами;
- регистрация с подтверждением e-mail, восстановление пароля, личный кабинет и история заказов;
- корзина и избранное (для авторизованных пользователей);
- оформление заказа одной транзакцией: создание заказа и позиций, фиксация цен, списание остатков, очистка корзины;
- приветственная скидка 15 % на два первых заказа;
- отзывы только после покупки, публикуются после модерации.

**Для администратора**
- дашборд, управление товарами, остатками (с оповещением о низком запасе), заказами и их статусами;
- акции с привязкой товаров и автоматическим пересчётом цен;
- модерация отзывов.

## База данных

MySQL: **10 таблиц + 1 представление** (`v_cart_details` — расчёт сумм корзины).

| Таблица | Назначение |
|---|---|
| `user` | пользователи, роли `user` / `admin`, хеш пароля, токены |
| `category`, `product` | категории и товары (цены, скидки, остатки) |
| `promo`, `promo_product` | акции и связь «акция ↔ товар» |
| `cart`, `cart_item` | корзина |
| `orders`, `order_item` | заказы (статусы `pending`, `processing`, `completed`, `cancelled`) и позиции |
| `favorites` | избранное (уникальная пара пользователь + товар) |
| `reviews` | отзывы с рейтингом 1–5 и флагом модерации |

Внешние ключи и уникальные индексы; изменения схемы оформлены миграциями Yii2 (`migrations/`).

## Безопасность

Хеширование паролей (bcrypt), защита от SQL-инъекций (ActiveRecord и параметризованные запросы), XSS (экранирование вывода), CSRF-токены, разграничение доступа к админ-разделу и чужим заказам.

## Тестирование

96 проверок по направлениям: функциональность, база данных, юзабилити, совместимость, безопасность (описание — в `diplom1.md`). Руководство администратора — `admin_manual_ru.md`.

## Запуск

```bash
composer install
cp config/db-local.example.php config/db-local.php   # впишите свои данные подключения к MySQL
php yii serve
```

Данные подключения к БД хранятся в `config/db-local.php`; он в `.gitignore` и в репозиторий не попадает.

## Структура

migrations/    миграции БД
